# Findings

- Human access currently accepts a password equal to ADMIN_TOKEN or that same token as a bearer credential. HMAC browser sessions also use ADMIN_TOKEN. Both entry paths must be removed rather than retained as alternate administrator access.
- The Worker protects application assets, inbox and administrative mutations through humanIdentity. Attachment downloads have their own identity checks and require explicit regression coverage.
- Device connector authentication and agent MCP authentication are separate machine contracts and are not interactive user sign-in. Preserve their existing scope and tokens.
- Public main is clean at c53a235 and matches origin/main after fetch. Production deployment identifiers remain in ignored local configuration; private adapters and user data must not enter this branch.
- Verified the actual provider issuer and discovery document. ID Token/UserInfo contain no role claim, but authenticated access-token introspection joins the live user row, checks enabled/revoked/expiry/client/app access, and returns roles:[admin] exactly for user level3. Administrator authorization must use that introspection result, not identity profile or email.
- App allow_all=false is separate from OAuth confidential-client authentication. Enforce both a private app policy at the provider and client_secret_basic for server-side token exchange; still require the live admin role in Message Center so an explicit ordinary-user assignment cannot grant data access.
- Provider access tokens expire after300s. Use the mature server-side session pattern with an opaque cookie, encrypted token storage and an atomic refresh lease so ordinary browsing does not force a full login every five minutes or race rotating refresh tokens. Add a new table to the current schema and provision only that table; do not retain old password sessions or write compatibility migrations.
- Existing production Message Center has only the legacy admin/agent/connector secrets. Requested the exact client_id and protected client-secret location, since Cloudflare secret listing cannot read existing plaintext. Implementation and offline validation can proceed independently.
- User confirmed the client does not yet exist. The provider already has an initial dynamic-registration secret, but its local safe storage location is unknown; asked the user for that location. Do not overwrite the existing registration credential or synthesize client rows directly in D1. Production registration, private policy and deployment remain pending this credential.
- A raw issuer identifier without a trailing slash must remain unchanged when validating the ID Token. URL normalization would otherwise break real provider callbacks despite passing a slash-terminated fixture.
- Rotating refresh tokens require a single owner. An expired owner invalidates the session instead of allowing another request to reuse an uncertain refresh token; late results cannot recreate a logged-out session. Provider metadata alone is cached; administrator authorization is checked live.
- Logout redirects to a separate signed-out page so the existing provider SSO cookie cannot automatically sign the browser back into the application.
- The test authentication wrapper delegates business DB methods dynamically, preserving the existing batch/lease-race negative controls. Tests use a real signed authorization-code exchange and encrypted D1 sessions instead of an administrator bearer bypass.

## Production cutover

- The user could not recover the initial registration credential. Provider source and independent review established that it is only checked for new dynamic client registrations; replacing it does not alter existing clients, client secrets, sessions, or issued tokens. The earlier credential-location blocker is resolved by this bounded rotation.
- Registered exactly one dedicated confidential client through the provider's supported registration endpoint. The new client had no access policy, individual grants, access tokens or refresh tokens before restriction. An explicit deny-by-default app policy and corresponding operator audit row were created only for that client; no existing user permissions changed. Live provider UI also describes missing policies as default deny.
- Kept the replacement registration credential, registration management credential, client secret and session key under Windows CurrentUser DPAPI with restricted filesystem ACLs. The normal local credential store now contains the unchanged machine credentials and the new OIDC secrets. Existing private device tooling retains its original encrypted store.
- Production received only the new session table and expiry index after a recovery bookmark was recorded privately. Existing database migrations were already applied. Wrangler required the verified account identifier in the process environment for D1 operations; no account was guessed and no global environment was changed.
- Real administrator authorization-code login loaded the inbox. The original login's refresh token was consumed once and replaced within the same token family while the inbox remained usable. Anonymous private routes and the actual retired administrator bearer returned 401. The unchanged machine credential successfully listed all eight MCP tools without consuming or sending a message.
- Automated form navigation to logout was blocked by Edge with ERR_BLOCKED_BY_CLIENT before a verified server response. Browser protection settings were not changed. The user reported manual logout success; a later automation retry was still blocked. Existing session rows cannot be independently correlated to that manual action, so do not claim automated production logout or server-side deletion was proved. Local logout, revocation and race regressions had already passed.
- Removed the unused production administrator secret after OIDC login and machine authentication were verified. The current production version and credential expiry are recorded only in private operational files. No iPad state, source collection or physical-message delivery was exercised by this authentication cutover.
